We encountered an issue with our Nginx and PHP-FPM setup on the Kubernetes cluster this morning, which halted its functionality. Investigate and rectify the issue:  
  
The pod name is `nginx-phpfpm` and configmap name is `nginx-config`. Identify and fix the problem.  

Once resolved, copy `/home/thor/index.php` file from the `jump host` to the `nginx-container` within the nginx document root. After this, you should be able to access the website using `Website` button on the top bar.  
 
`Note:` 
- The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

### Answer

1. Click on the website page in the top right corner.
2. The web page that opens shows us a `404 page not found`.
3. Lets investigate the configmap using;

```
kubectl describe configmap nginx-config
```

4. Within the configMap, we focus on the comment and root folder;

```
# Set nginx to serve files from the shared volume!  
root /var/www/html;
```

5. Next we investigate the pod using;

```
kubectl describe pods nginx-phpfpm
```

7. From the output we identify two containers, each has the shared-files volume mounted but we notice the mount points differ.

```
Containers:
  php-fpm-container:
  Mounts:
      /var/www/html from shared-files (rw)

  nginx-container:
  Mounts:
      /usr/share/nginx/html from shared-files (rw)
```

In this scenario, the php-fpm-container will process code before serving it to the nginx-container. Both containers have a shared volume mounted that gives both containers access to the code. However, because the mounting point is wrong on the nginx container, the nginx server is unable to serve the website. This is because the nginx server looks for the files in the `/var/www/html` directory but this does not exist due to the wrong mount point. 

8. Lets output the pod manifest to a file.

```
kubectl get pods nginx-phpfpm -o yaml > nginx-phpfpm.yaml
```

9. Delete the existing pod.

```
kubectl delete -f nginx-phpfpm.yaml
```

10. Edit the manifest and change the nginx-container mounting point of the shared-files to `/var/www/html`.
11. Apply the new manifest

```
kubectl create -f nginx-phpfpm.yaml
```

12. Once the pods is deployed, copy the file from the jump host to the directory.

```
kubectl cp /home/thor/index.php nginx-phpfpm:/var/www/html -c nginx-container
```

13. Check the website button again and web page with the PHP version and information will be display. 
14. Click check to complete the task.
