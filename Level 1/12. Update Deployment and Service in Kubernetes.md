An application deployed on the Kubernetes cluster requires an update with new features developed by the Nautilus application development team. The existing setup includes a deployment named `nginx-deployment` and a service named `nginx-service`. Below are the necessary changes to be implemented without deleting the deployment and service:

1. Modify the service nodeport from `30008` to `32165`
2. Change the replicas count from `1` to `5`
3. Update the image from `nginx:1.19` to `nginx:latest`

`Note:` 
- The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

### Answer

1. Output the service into a yaml file.

```
# Check the service exist
kubectl get services nginx-service

# Output service manifest as yaml file
kubectl get services nginx-service -o yaml > nginx-service.yaml
```

2. Do the same with the deployment manifest.

```
# Check the deployment exist
kubectl get deployment.apps nginx-deployment.yaml

# Output service manifest as yaml file
kubectl get deployment.apps nginx-deployment.yaml > nginx-deployment.yaml
```

3. Edit the service manifest and change the `NodePort` from `30008` to `32165` and save.
4. Edit the deployment manifest and change the image from `nginx:1.19` to `nginx:latest`.
5. Also edit the replicas count from `1` to `5` and save.
6. Apply the services configuration; 

```
kubectl apply -f nginx-service.yaml`
```

7. Apply the deployment configuration; 

```
kubectl apply -f nginx-deployment.yaml
```

8. Check the configuration has updated for the service; and the nodeport is `32165`

```
kubectl describe services nginx-service
```

9. Check the deployment has updated and new instances have launched.

```
kubectl describe deployment.apps nginx-deployment
```

10 if everything is updated, click check to complete the task.
