The Nautilus DevOps team is diving into Kubernetes for application management. One team member has a task to create a pod according to the details below:

1. Create a pod named `pod-httpd` using the `httpd` image with the `latest` tag. Ensure to specify the tag as `httpd:latest`
2. Set the app label to http_app, and name the container as `httpd-container`.

**Note**: The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.


### Answer

1. Create a pod manifest file named `pod-httpd.yaml` with the following configuration;

```
apiVersion: v1
kind: Pod
metadata:
  name: pod-httpd
  labels:
    app: httpd_app
spec:
  containers:
    - name: httpd-container
      image: httpd:latest
      ports:
      - containerPort: 80 
```

2. Once the file is saved, create the pod using the file;

```
kubectl apply -f pod-httpd.yaml
```

3. Double check the pod and its status using the command;

```
kubectl get pods
```

4. You can click check to complete the task.
