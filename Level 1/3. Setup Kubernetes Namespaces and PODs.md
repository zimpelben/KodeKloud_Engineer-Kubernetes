The Nautilus DevOps team is planning to deploy some micro services on Kubernetes platform. The team has already set up a Kubernetes cluster and now they want to setup  some namespaces, deployments etc. Based on the current requirements, the team has shared some details as below:

- Create a namespace named `dev` and deploy a POD within it. Name the pod `dev-nginx-pod` and use the `nginx` image with the `latest` tag. Ensure to specify the as `nginx:latest`.

**Note**: 
- The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

### Answer

1. Create a namespace using the following command;

```
kubecrl create namespace dev
```

2. Create the pod manifest named `pod-nginx.yaml` with the following configuration;

```
apiVersion: v1
kind: Pod
metadata:
  name: dev-nginx-pod
  namespace: dev
  labels:
    app: nginx
spec:
  containers:
    - name: nginx-container
      image: nginx:latest
      ports:
      - containerPort: 80 
```

3. Once the file is saved, create the pod using the file;

```
kubectl apply -f pod-nginx.yaml
```

4. Check if the pod is running using the following command;

```
kubectl get pods -n dev
```

**Note**
- The `-n` option is to specify the `namespace`. If the command `kubectl get pods` is run, the context is set to the `default` namespace and there are no pods running in that namespace.

5. Click check to complete the task.
