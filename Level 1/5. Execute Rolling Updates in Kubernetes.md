An application currently running on the Kubernetes cluster employs the nginx web server. The Nautilus application development team has introduced some recent changes that need deployment. They've crafted an image `nginx:1.18` with the latest updates.

- Execute a rolling update for this application, integrating the `nginx:1.18` image. The deployment is named `nginx-deployment`.

Ensure all pods are operational post-update.

`Note:` 
- The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

### Answer

1. We can check the current image and deployment details with;

```
kubectl describe deployments.apps nginx-deployment 
```

2. The current image being used is `nginx:1.16`.
3. We can update the image using the following command;

```
kubectl set image deployments/nginx-deployment nginx-container=nginx:1.18
```

4. We can check the deployment rollout with the following command;

```
kubectl rollout status deployment nginx-deployment 
```

5. Output will be `deployment "nginx-deployment" successfully rolled out` if completed.
6. We can double check the deployment and see the the new image being used.

```
kubectl describe deployments.apps nginx-deployment 
```

7. Click check to complete the task.
