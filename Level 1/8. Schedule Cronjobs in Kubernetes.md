The Nautilus DevOps team is setting up recurring tasks on different schedules. Currently, they're developing scripts to be executed periodically. To kickstart the process, they're creating cron jobs in the Kubernetes cluster with placeholder commands. Follow the instructions below:  

1. Create a cronjob named `devops`.  
2. Set Its schedule to something like `*/11 * * * *`. You can set any schedule for now.  
3. Name the container `cron-devops`.    
4. Utilize the `nginx` image with `latest tag` (specify as `nginx:latest`).    
5. Execute the dummy command `echo Welcome to xfusioncorp!`.    
6. Ensure the restart policy is `OnFailure`.    

`Note:` 
- The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

### Answer

1. Create the cronjob manifest `devops`;

```
apiVersion: batch/v1
kind: CronJob
metadata:
  name: devops
spec:
  schedule: "*/11 * * * *"
  jobTemplate:
    spec:
      template:
        spec:
          containers:
          - name: cron-devops
            image: nginx:latest
            imagePullPolicy: IfNotPresent
            command:
            - /bin/sh
            - -c
            - echo Welcome to xfusioncorp!
          restartPolicy: OnFailure
```

2. Create cronjob with `kubectl apply -f devops.yaml`.
3. Once the cronjob is created, double check with `kubectl get cronjobs.batch`.
4. Click check to complete the task.
